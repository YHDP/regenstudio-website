The review surface is now the real post, rendered through the production pipeline, with the comment widget overlaid. No stripped-down copy.

Build it (per draft)

cd ~/Claude/regenstudio-website
~/.deno/bin/deno run --allow-read --allow-write build.ts \
  --comment-stage <slug> [--lang en|nl|pt] [--password <pw>]
python3 -m http.server 8000   # serve repo root

Share with external reviewers

  1. Build with --password → an encrypted artifact is written to /_review/<slug>-<id>/.
  2. Deploying it (a deliberate git add -f + an explicit, authorised git push) puts it at an unlisted, noindex URL on the live site.
  3. Share that URL + the review password. Reviewers comment/edit/delete, then “Copy feedback” → email to yvo.hunink@regenstudio.world. Nothing is stored or sent automatically.
  4. Apply their emailed feedback via the existing /review-blog flow. review.text/review.assets/published stay Yvo-only.

The comment stage never flips review flags or publishes. _comment-stage/ is local-only (gitignored + pre-push-blocked); only the encrypted _review/ artifact is ever deployable.
