Inzoomen — anonieme analytics

Hoe we website-analytics doen

Geen cookies. Geen tracking pixels. Geen cross-site identifiers. We tellen page visits via een dagelijks-roterende salt — onmogelijk om bezoekers over dagen heen te volgen.

1
Je browser stuurtpage-path + event-type
→
2
Server hashed je IP met eendagelijks-roterende salt
→
3
Raw events na 48 uur wegalleen aggregaten blijven
SHA-256( daily_salt : IP : User-Agent )

De salt rotereert elke 24 uur via een geautomatiseerde database-functie — daardoor is het onmogelijk om dezelfde bezoeker te identificeren over verschillende dagen heen. Deze architectuur valt buiten de cookie-toestemming-vereisten van ePrivacy Art 5(3) en is door CNIL erkend als consent-vrij. Lees mee in onze privacy-architectuur op GitHub →
